# Eterna

Sistema de captura, validação, venda e entrega de fotos do Tour do Maracanã. Protótipo funcional publicado em https://eterna.photo

- `index.html` · app completo (perfis admin, fotógrafo, vendedor, validador, cliente, quiosque)
- `agente/eterna-agente.py` · agente do ponto: lê o cartão de memória e entrega as fotos ao app
- `docs/DOCUMENTACAO-TECNICA.md` · documentação técnica v1: arquitetura, stack e versões, repositório, modelo de dados, fluxos (mermaid), integrações, infraestrutura, design system, segurança
